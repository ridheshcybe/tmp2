# AeroTwin — Documentation

**AI-Enabled Real-Time Digital Twin for aero piston engine health monitoring, fault prediction and mission reliability** (SIH 26054 / DRDO Tapas-BH-201).

Everything in this workspace, documented. Start here.

> **📖 Beautiful single-page version:** [`docs/aerotwin-docs.html`](aerotwin-docs.html) — the entire documentation set as one styled, navigable site (scrollspy nav, copyable code, expandable endpoints). Open it in any browser.

## The two systems

```
AeroTwin workspace
│
├── 1. Standalone frontend  (src/frontend)          ← what run.bat opens
│     Static HTML/JS pages, served by serve.py on :8000.
│     Talks to the backend via aerotwin-api.js (REST proxy + direct WS).
│
└── 2. SIH digital twin    (sih/)                   ← the engine room
      ├── simulator/   physics telemetry generator (fault injection)
      ├── ml/          training + inference pipeline (the AI)
      ├── backend/     FastAPI REST + WebSocket API on :8081
      └── frontend/    React cockpit (Vite) with the cutaway viewer
```

## How a telemetry frame flows

```
simulator/telemetry_gen/engine_model.py     physics step (10 Hz)
        │  + fault_injection.py              fault effects applied
        ▼
backend/services/simulator.py               asyncio tick loop → frame dict
        ▼
backend/routes/mission.py process_and_store frame → SQLite → ML pipeline
        ▼
backend/services/digital_twin.py  ONE ORCHESTRATOR:
        ├─ ml/physics_baseline.py            expected sensor values + residuals
        ├─ backend/services/anomaly.py       anomaly score + fault class (ML or fallback)
        ├─ backend/services/health_index.py  Engine Health Index 0–100 (explainable)
        ├─ backend/services/fault_prediction.py  criticality + recommended action
        ├─ backend/services/rul.py           Remaining Useful Life + RTB alerts
        └─ alerts + sensor status assembly
        ▼
backend/websocket_handler.py                broadcast to all WS clients
        ▼
src/frontend/aerotwin-api.js                flatten() → pages render live KPIs
```

## Quick start

```bash
run.bat          # boots backend :8081 (if not up) + static server :8000, opens the dashboard
```

Manual:
```bash
# backend (from workspace root — imports use the backend.* package prefix)
cd sih && python -m uvicorn main:app --host 127.0.0.1 --port 8081

# frontend
cd src/frontend && python serve.py        # → http://localhost:8000/
```

Interactive API docs are auto-generated by FastAPI: **http://localhost:8081/docs** (Swagger) and **/redoc**.

## Key facts

- **Engine**: `TAPAS-BH-201-001`, 4-cylinder air-cooled aero piston, simulated at 10 Hz.
- **Database**: SQLite at `sih/data/aerotwin.db` (aiosqlite, async, batched writes).
- **Models**: 4 scikit-learn models in `sih/ml/models/` (`anomaly.joblib`, `classifier.joblib`, `degradation.joblib`, `rul.joblib` + `bundle.json`). Train with `cd sih && train.bat`. If models are missing, everything degrades to a documented rule-based fallback instead of breaking.
- **Ports**: 8000 static frontend · 8081 FastAPI · 8080 Node backend (legacy, see `sih/backend/package.json`).
