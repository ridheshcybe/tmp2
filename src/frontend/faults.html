Guided demo (about 4 minutes)
  1. Press Start mission so the simulator is running.
  2. Set a severity, then press Inject on Overheating.
  3. Watch the step rail under the card: Selected › Starting › Active.
  4. Watch the pipeline panel above catch the class, EHI and anomaly score.
  5. Press Clear all faults to return to nominal, then open Blackbox Logs.
What each fault changes
Every card names the sensor signature the ML pipeline keys on. Severity 0 is the healthy baseline and 1 is the full fault. Inject two or three at once to show the classifier separating them from the residual pattern instead of tripping a single threshold.
